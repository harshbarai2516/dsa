# Data Structures and Algorithms

A personal repository for building problem-solving skills through consistent DSA practice. I aim to solve **4–6 problems each day**, document my solutions, and track my progress over time.

This repository is both a learning log and a public portfolio of my work. Solutions are added as I study new topics and revisit earlier problems.

## Goals

- Practice DSA consistently and develop strong problem-solving fundamentals.
- Write clear, readable solutions and understand why they work.
- Record each problem's approach and time and space complexity.
- Revisit problems to improve solutions and reinforce concepts.

## Repository Structure

Problems are grouped by topic. As the repository grows, each solution should include enough context to identify and review the problem.

```text
.
├── arrays/
├── patterns/
└── README.md
```

Suggested solution file format:

```text
<topic>/<problem-name>.py
```

For example: `arrays/two-sum.py`.

## Solution Notes

For each problem, aim to include:

- **Problem:** name and link to the statement, if available
- **Approach:** a short explanation of the idea
- **Complexity:** time and space complexity
- **Solution:** readable, tested code

## Running a Python Solution

From the repository root, run a solution with Python:

```bash
python patterns/main.py
```

Replace the path with the file you want to run. Some solutions may define a function or class without running it automatically; in that case, add a small example call or test at the bottom of the file.
